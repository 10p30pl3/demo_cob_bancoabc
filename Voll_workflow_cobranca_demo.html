Configuração de envio

Todos os botões enviam uma requisição POST para o proxy Render, que repassa o payload para o servidor da Voll usando Content-Type: application/json.

Modo ativo: envio real via proxy Render. A página chama https://demo-cob-bancoabc.onrender.com/api/regua-cobranca, e o proxy repassa a requisição para o endpoint Voll.
